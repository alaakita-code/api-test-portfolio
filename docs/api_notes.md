# API 探索筆記

- 被測對象：JSONPlaceholder
- Base URL：`https://jsonplaceholder.typicode.com`
- 最後更新：2026-11-14
- 本文件為探索結果之摘要；原始紀錄詳見 `docs/api_observed.md`。

## 1. 基本資訊

資料來源為被測對象之官方首頁。

| 項目 | 內容 |
|---|---|
| 驗證機制 | 無；無須金鑰或註冊 |
| 資源與筆數 | posts 100、comments 500、albums 100、photos 5000、todos 200、users 10 |
| 支援之方法 | GET、POST、PUT、PATCH、DELETE |
| 巢狀路徑 | 僅支援一層，例如 `/users/1/posts` |
| 篩選 | 僅支援查詢參數，例如 `?userId=1` |
| 寫入之保存 | 不保存；POST、PUT、PATCH、DELETE 僅回傳模擬結果 |

## 2. 探索問題與結果

下表列示撰寫測試前所提出之 10 項問題，及實際觀察所得之結果。

| 編號 | 問題 | 結果 | 依據 |
|---|---|---|---|
| Q1 | `GET /posts/1` 回傳之欄位及其型別為何 | userId、id 為整數；title、body 為字串 | 觀察 3 #2 |
| Q2 | `POST /posts` 之狀態碼及回傳之 id 為何 | 201；id 為 101 | 觀察 3 #5 |
| Q3 | `DELETE /posts/1` 之狀態碼及回應內容為何 | 200；`{}` | 觀察 3 #8 |
| Q4 | `/posts/0`、`/posts/101`、`/posts/-1`、`/posts/abc` 之狀態碼為何 | 均為 404，內容為 `{}` | 觀察 3 #10 至 #13 |
| Q5 | 不存在之路徑回應何種狀態碼 | 404，內容為 `{}` | 觀察 3 #14 |
| Q6 | `?userId=999` 回應空清單或錯誤 | 200 與空清單 `[]` | 觀察 3 #15 |
| Q7 | `POST /posts` 送出空白內容時是否遭拒絕 | 未遭拒絕；回應 201 與 `{"id":101}` | 觀察 3 #16 |
| Q8 | `PUT /posts/101`、`DELETE /posts/101` 之狀態碼為何 | PUT 回應 404；DELETE 回應 200 | 觀察 3 #17、#18 |
| Q9 | 重複送出同一請求時，結果是否一致 | 一致 | 觀察 3 #19、#20 |
| Q10 | 一般情形下之回應時間為何 | 本機實測平均每個測試約 1 秒（含測試工具啟動時間，樣本僅兩次執行） | 本機執行：10 個測試耗時 10.73 秒、21 個測試耗時 20.69 秒 |

Q1 至 Q9 之結果先由瀏覽器觀察取得，其後已以 Python requests 於本機及 CI 執行測試驗證，結果相同。

## 3. 已知限制

- 被測對象不保存寫入結果，故無法驗證寫入後查詢之資料一致性。
- 被測對象不驗證輸入（Q7），亦未設登入機制，故輸入驗證與權限測試不在範圍內。
- 對不存在之 id，更新與刪除之行為不一致（Q8）。
- 讀取類之回應多由 Cloudflare 快取提供，故重複請求測試所驗證者可能為快取之一致性。
- 被測對象為提供模擬資料之示範服務。測試結果僅反映測試設計與自動化之方法，不代表正式產品之品質。
- 測試依賴外部服務。因服務中斷所致之測試失敗屬環境問題，而非測試腳本問題。
